# AION2 利益ファインダー

AION2（グローバル版）のマーケットで、利益が出る出品物を探すツールです。GitHub が毎時自動で相場を集め、スマホのブラウザで見られるページとして公開します（無料）。

| タブ | わかること |
|---|---|
| 転売 | 今の最安出品を買って出し直すと、税・手数料を引いても利益が残る品 |
| 売り時 | 手持ちの品をいくらで出せば売れるか、今が7日相場より高いか |
| 製作 | 登録したレシピで、素材を買って作る・素材のまま売るの損益 |
| クーナ | キナ箱の値段から、1クーナで何キナ買えるかの比較 |
| 設定 | 税率・手数料・しきい値、レシピの書き出し、サーバー一覧 |

データ元は [aion2.exchange](https://aion2.exchange)（有志による非公式の相場サイト）です。価格は「出品中の最安値の観測値」で成約価格ではなく、24時間の販売数はサイト側の推定です。

## セットアップ（初回だけ、10分ほど）

1. GitHub で新しいリポジトリを作り（Public 推奨。Private だと Pages に有料プランが必要）、このフォルダの中身を全部アップロードします。`.github` フォルダも忘れずに。
2. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にします。
3. **Actions** タブで「相場を収集して公開」を選び、**Run workflow** を押します。
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` を開きます。初回はサーバー未設定なので、**設定タブ**にサーバー一覧が出ます。
5. `config.json` の `servers` に自分のサーバー名かIDを入れて保存（コミット）します。例：`"servers": ["Lumiel"]`。保存すると自動で再収集されます。
6. スマホでページを開き、ホーム画面に追加しておくとアプリのように使えます。

以降は毎時17分（UTC）に自動更新されます。

## 設定（config.json）

| 項目 | 意味 |
|---|---|
| `servers` | 集めるサーバー（名前かID）。複数可。増やすほど相手サイトへの負荷が増えるので必要な分だけ |
| `history_days` | 履歴を見る日数（7） |
| `history_budget_per_server` | 1回の実行で7日履歴を取る品目数の上限 |
| `tax_rate` / `fee_rate` | 税率・出品手数料の初期値（ページの設定タブで上書きできる） |
| `request_delay_sec` | API呼び出しの間隔（秒） |

## レシピの登録

製作タブの「レシピを追加」で、完成品と素材を候補から選んで保存します。レシピはそのスマホに保存されます。
設定タブで書き出した内容を `recipes.json` に貼ってコミットすると、どの端末でも同じレシピが出て、素材の7日履歴も優先して集めます。

## 判定のしかた

- 手取り = 売値 ×（1 − 税率 − 出品手数料率）
- 転売の売値目安 = 24時間の販売平均単価と7日中央値の低いほう（慎重モード。設定でオフにできる）
- 転売の利益 = 売値目安の手取り − 今の最安値
- 並び順の「利益×24h販売数」は、売れる速さも加味するための目安（20個で頭打ち）。最安値で何個買えるかはAPIからわからないので、買う前にゲーム内で数量を確認してください

## 注意

- 非公式データです。購入前に必ずゲーム内の価格と数量を確認してください。
- 精算には1日の上限（信頼度で決まる）があります。大きく転売すると、売上がすぐ受け取れないことがあります。
- このツールはゲームクライアントには触れず、公開サイトのデータを読むだけです。
- 相手サイトは個人運営です。取得間隔を短くしすぎないでください。

## 手元のPCで動かす場合

```
python collector/collect.py --list-servers                 # サーバー名とIDの確認
python collector/collect.py --servers Lumiel --out site/data
cd site && python -m http.server 8000                      # http://localhost:8000 を開く
```
